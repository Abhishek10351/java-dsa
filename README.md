# Java DSA Journey

This repository tracks a focused **Data Structures and Algorithms (DSA)** journey in Java for learners who already know Java basics.

## Goal
Build strong problem-solving skills for coding interviews and real-world programming.

## Focus Plan
1. **Complexity Basics**: Big-O, time vs space tradeoffs
2. **Core Data Structures**: Arrays, Strings, Linked Lists, Stacks, Queues, Hashing
3. **Problem-Solving Patterns**: Two pointers, Sliding window, Prefix sum, Binary search
4. **Recursion & Backtracking**
5. **Trees & BST**
6. **Heaps, Greedy, and Graph Basics**
7. **Dynamic Programming**

## Practice Approach
- Solve consistently (small daily targets)
- Start with easy problems, then medium, then hard
- Revise mistakes and patterns weekly
- Focus on writing clean Java solutions with clear logic
